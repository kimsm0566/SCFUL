# Literature Notes

This directory stores the related papers and paper-level notes.

## Layout

- `papers/`: original PDF files
- `summaries/`: per-paper summaries and reading notes
- `comparison_matrix.md`: comparison between prior work and the proposed idea

## Core Papers

- SCU: centralized machine unlearning for jointly trained semantic communication encoder-decoder models
- SSFU: selective semantic feature unlearning for SemCom-enabled federated learning
- SeFUL: client/class-level federated unlearning under non-IID data in intelligent wireless networks

## Reconstruction and Generative Evaluation Papers

- I2I-GU: masked image-to-image reconstruction unlearning with retain/forget FID, IS, and CLIP
- SalUn: generation unlearning accuracy together with retained-generation FID
- GUIDE: target-identity similarity together with global FID preservation
- Forget-Me-Not: target concept removal while preserving unrelated generation knowledge
