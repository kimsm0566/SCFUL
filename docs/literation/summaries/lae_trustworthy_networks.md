## Stated motivation (abstract-level only)

1. **UAV, ground-station, and user coordination needs data trust.** The article frames trustworthy intelligent networks as necessary for security-sensitive, time-critical low-altitude applications.
2. **Malicious data can affect a semantic knowledge base.** Its abstract motivates federated unlearning as a way to mitigate those effects in a UAV-enabled semantic-communication architecture.
3. **Rebuilding the semantic knowledge base is too costly.** The unlearning framework is explicitly positioned as a means to improve data trust without retraining the knowledge base from scratch.

## Scope for this project

This is an application/architecture paper linking UAV-enabled SemCom and federated unlearning. It should be cited as evidence for the trust and malicious-data motivation, not as an existing method for whole-client, joint reconstruction-codec unlearning.
