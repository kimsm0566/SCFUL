## Stated motivation (abstract-level only)

1. **A shared semantic knowledge base is trained from multiple users and is needed for accurate semantic extraction.** Federated learning is used to support that collaboration without raw-data sharing.
2. **Invalid knowledge is a reliability problem.** The abstract specifically names outdated, irrelevant, and harmful user data as contributions that can compromise semantic-knowledge-base reliability.
3. **Removing invalid influence without full retraining is the efficiency requirement.** The proposed federated unlearning mechanism is motivated as a way to remove the impact of invalid data while preserving knowledge-base reliability and avoiding full retraining cost.

## Scope for this project

This is directly relevant evidence that federated unlearning is considered necessary for multi-user semantic communication. Its target is the shared semantic knowledge base, not the jointly trained reconstruction codec in this project.
