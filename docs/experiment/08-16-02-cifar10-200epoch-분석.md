# CIFAR-10 200 Epoch 삭제 행동 비교 분석 (seed 0)

이 문서는 `outputs/cifar10_behavior/20260816T114133Z_seed-0/`의 CUDA 실행 결과를 기록한다. 20 epoch 결과에서 CIFAR-10 reconstruction이 아직 학습 중일 가능성이 확인되어, 삭제 전 모델, 삭제 대상 제외 재학습 모델, 재학습 복제본, SCU forget-only, SCU self-sharing을 모두 200 epoch로 다시 학습했다.

## 결론

- **20 epoch는 충분하지 않았다.** 삭제 전 모델의 epoch 평균 reconstruction loss는 epoch 19의 `0.016369`에서 epoch 199의 `0.013505`로 추가로 약 17.5% 감소했다.
- **200 epoch는 20 epoch보다 훨씬 적절한 비교 조건이다.** 삭제 대상 제외 재학습 모델의 retained held-out MSE는 `0.012949`에서 `0.009518`로 약 26.5% 낮아졌고, reconstruction grid의 색과 큰 윤곽도 더 분명해졌다.
- **다만 200 epoch에서도 완전한 수렴이라고 단정할 수는 없다.** Original reconstruction loss는 epoch 99의 `0.013920`에서 epoch 199의 `0.013505`로 약 3.0% 더 감소했다. 다음 길이 검증은 300 또는 400 epoch와 held-out MSE plateau를 기준으로 결정해야 한다.
- **SCU self-sharing의 output은 삭제 대상 제외 재학습 모델과 재학습 변동성 수준으로 가깝다.** 반면 forget-only는 200 epoch에서도 전체 reconstruction을 과도하게 파괴한다.

## 설정

20 epoch run과 dataset split, codec, optimizer, learning rate, channel, seed는 동일하다. 바뀐 것은 original/retrain/retrain replica/SCU 두 변형의 epoch 수를 모두 200으로 맞춘 것뿐이다.

| 항목 | 값 |
| --- | --- |
| Dataset | CIFAR-10, 32x32 RGB, `ToTensor` |
| Target client | cat, deer, dog, frog 각 1,500개 + automobile 전체 5,000개 = 11,000개 |
| Retained training data | 39,000개, automobile sample 0개 |
| Channel | power-normalized latent, AWGN 10 dB |
| Codec | Conv encoder / ConvTranspose decoder, latent 64, base channel 32 |
| Optimizer | 새 Adam, learning rate `1e-4`, beta `1e-4` |
| Epoch | original/retrain/retrain replica/SCU 모두 200 |
| Batch size | 128 |

| 모델 | Step | Sample exposure |

## 학습이 실제로 더 진행됐는가

아래는 original codec의 epoch 평균 training reconstruction loss다. 이 값은 training에서 posterior sampling과 AWGN을 포함한 reconstruction loss이며, held-out metric과 동일한 수치는 아니지만 학습 진행 방향을 보여 준다.

| Epoch | Reconstruction loss |
| ---: | ---: |
| 0 | 0.043530 |
| 19 | 0.016369 |
| 49 | 0.014649 |
| 99 | 0.013920 |
| 149 | 0.013664 |
| 199 | 0.013505 |

epoch 0--19에서 가장 큰 감소가 있었지만 epoch 20--200에도 감소가 지속됐다. 따라서 20 epoch 결과를 최종 reconstruction quality나 deletion behavior의 근거로 사용하면 모델 under-training 효과가 섞일 수 있다. 반면 epoch 100--200의 개선은 작아졌으므로, 다음 run은 무조건 더 긴 epoch를 정하기보다 held-out MSE 변화가 충분히 작아지는지 확인하는 방식이 적절하다.

`metrics/training_by_epoch.csv`에는 다섯 모델의 200개 epoch 평균 loss가 모두 저장되어 있다.

## 20 Epoch와 200 Epoch의 reconstruction 비교

아래는 channel noise 없는 posterior-mean 경로의 MSE다. 낮을수록 원본 이미지 복원이 좋다.

| Probe / 모델 | 20 epoch | 200 epoch |
| --- | ---: | ---: |
| retained held-out / 삭제 대상 제외 재학습 | 0.012949 | 0.009518 |
| target member shared_high / 삭제 대상 제외 재학습 | 0.012325 | 0.009246 |
| target member target-specific / 삭제 대상 제외 재학습 | 0.018339 | 0.013504 |
| retained held-out / SCU self-sharing | 0.012342 | 0.009298 |
| target member target-specific / SCU self-sharing | 0.017481 | 0.012849 |

200 epoch에서 모든 group의 MSE가 눈에 띄게 낮아졌다. 특히 target-specific automobile group도 삭제 대상 제외 재학습 모델에서 `0.013504`까지 복원된다. Automobile 학습 sample이 retained set에는 전혀 없다는 조건은 그대로이므로, “target-specific class는 반드시 복원 불가능해야 한다”는 해석은 여전히 맞지 않는다.

## 삭제 대상 제외 재학습 모델과의 output 차이

`FG_output`은 각 모델의 reconstruction과 삭제 대상 제외 재학습 모델 reconstruction의 MSE다. 낮을수록 deletion 후 기대되는 행동에 가깝다. 재학습 복제본은 동일 retained data를 다시 학습했을 때의 자연스러운 변동성이다.

### Posterior-mean 경로

| Probe | 재학습 복제본 | SCU self-sharing | self-sharing / 복제본 | SCU forget-only |
| --- | ---: | ---: | ---: | ---: |
| retained held-out | 0.000614 | 0.000550 | 0.90 | 0.282119 |
| target member / shared_high | 0.000568 | 0.000496 | 0.87 | 0.233111 |
| target member / target-specific | 0.000759 | 0.000762 | 1.00 | 0.276579 |
| target held-out / shared_high | 0.000614 | 0.000542 | 0.88 | 0.251631 |
| target held-out / target-specific | 0.000793 | 0.000770 | 0.97 | 0.263451 |

Self-sharing은 모든 probe에서 재학습 복제본 변동성의 `0.87--1.00`배다. 즉 paired output 기준에서는 self-sharing과 삭제 대상 제외 재학습 모델의 차이가, 재학습을 한 번 더 했을 때의 차이와 같은 규모다.

단, self-sharing의 target-specific MSE(`0.012849`)는 삭제 대상 제외 재학습 모델 MSE(`0.013504`)보다 조금 낮다. 이것이 target knowledge 잔존인지 단순 stochasticity인지는 seed 0 하나로 구분할 수 없다. Output functional gap, membership attack, multi-seed 결과를 함께 봐야 한다.

### AWGN 10 dB 경로

| Probe | 재학습 복제본 | SCU self-sharing | SCU forget-only |
| --- | ---: | ---: | ---: |
| retained held-out | 0.002670 | 0.002336 | 0.282880 |
| target member / shared_high | 0.002517 | 0.002121 | 0.234019 |
| target member / target-specific | 0.003405 | 0.003077 | 0.277349 |
| target held-out / shared_high | 0.002712 | 0.002323 | 0.252543 |
| target held-out / target-specific | 0.003397 | 0.003077 | 0.264346 |

Channel noise를 넣어도 self-sharing은 재학습 변동성 범위 안에 있고, forget-only는 크게 벗어난다.

## SCU 두 변형의 학습 곡선

Forget-only의 target MSE는 epoch 0에서 `0.164940`, epoch 19에서 `0.266628`, epoch 199에서 `0.266692`였다. 즉 20 epoch 전후에 이미 target reconstruction을 크게 손상시키는 상태에 도달했고, 이후 180 epoch는 거의 추가 변화를 만들지 않았다.

Self-sharing의 target MSE와 retained MSE는 다음처럼 안정적이었다.

| Epoch | Target MSE | Retained MSE |
| ---: | ---: | ---: |
| 0 | 0.015121 | 0.013483 |
| 19 | 0.014813 | 0.013105 |
| 99 | 0.014951 | 0.013102 |
| 199 | 0.014940 | 0.013030 |

따라서 더 긴 SCU adaptation 자체가 self-sharing의 target/retained reconstruction을 크게 변화시키지는 않았다. 200 epoch의 주요 효과는 base codec과 삭제 대상 제외 재학습 모델을 더 잘 학습시킨 데 있다.

## 정성 결과

200 epoch reconstruction grid에서는 20 epoch보다 차량·동물의 큰 윤곽과 색 구성이 조금 더 명확하다. 그러나 세부 texture는 여전히 흐리다. 이는 추가 epoch만의 문제가 아니라 latent 64, 작은 decoder, pixel MSE 중심 학습의 한계일 수 있다.

Forget-only 출력은 거의 검은 화면으로 붕괴한다. 이는 target만 선택적으로 삭제한 결과가 아니라 전체 codec utility가 파괴된 결과다. Self-sharing 출력은 삭제 전·삭제 대상 제외 재학습 출력과 시각적으로 유사하다.

## 다음 판단

1. 이후 비교 실험의 기본 조건은 **20 epoch가 아니라 200 epoch**로 두는 편이 타당하다.
2. 200 epoch 이후 loss가 완전히 멈춘 것은 아니므로, original-only 300/400 epoch run으로 held-out MSE plateau를 확인한다.
3. Multi-seed(최소 3개)에서 self-sharing의 target-specific MSE와 FG_output을 반복해, 재학습 변동성과 실제 target knowledge 잔존을 분리한다.
4. 충분히 학습된 codec을 기준으로 federated joint forgetting, distributed repair, conflict-aware aggregation을 평가한다.
