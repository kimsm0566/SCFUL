# Experiment Plan

## Main Question

Can a reconstruction semantic communication codec remove a whole client's contribution while preserving retained-client reconstruction utility without raw-data centralization?

## Main Codec and Data Budget

본 실험의 기본 backbone은 `variational_deepjscc_cifar10_v3`이다. 원본 DeepJSCC의
5-layer encoder/decoder topology를 사용하되 마지막 encoder output을 posterior mean과
softplus standard deviation으로 확장한다. Initial log-variance는 `-7`, posterior
standard-deviation floor는 `1e-6`, prior KL reduction은 latent 합과 batch 평균을 사용하는
`batchmean_sum`이다. 프로젝트 소유 codec은 VariationalDeepJSCC 하나이며,
Exact SCU Table-2 model은 현재 지원하지 않는다.

Reconstruction codec과 config에는 classifier를 넣지 않는다. Semantic 평가가 필요한
후속 unlearning run은 별도 GroupNorm-SiLU CIFAR-10 classifier를 remaining-client
clean raw image로 새로 연합학습해 freeze하고, 모든 codec의 decoded image에 같은
외부 observer를 적용한다. Target client를 classifier 학습/validation에서도 제외하며
classifier CE를 codec으로 역전파하지 않는다. Model state, optimizer, FedAvg,
checkpoint를 공유하지 않는다. 과거 49k observer는 legacy 평가 재현용이다.

- Dataset: CIFAR-10
- Clients: 10
- Client training samples: 총 49,000개, client당 4,900개
- Public calibration samples: class당 100개, 총 1,000개
- External classifier pool: target 제외 remaining 44,100개; 기본 client-local validation 10% 분리
- Batch size: 200
- Initial FL rounds: pilot 20, main 800
- Optimizer: Adam, round 1--349 learning rate 0.001, round 350부터 0.0001
- Gradient clipping: 사용하지 않음
- Codec objective: batch-mean per-example RGB pixel SSE weight 1, batch-mean
  per-example latent KL-sum VIB beta 0.0001
- Training augmentation: none
- Channel bandwidth: source real values 3,072, transmitted real values 1,024,
  complex channel uses 512, complex channel bandwidth ratio 1/6
- Primary reconstruction evaluation: sampled posterior, Monte Carlo 10회
- Main non-IID splits: balanced 2-class/client, equal-size Dirichlet 0.1
- Channel for initial training: AWGN, 20 dB
- Default reconstruction evaluation: official CIFAR-10 test 10,000장, paired AWGN 20 dB

Public 1,000개를 class-balanced하게 먼저 분리한 뒤 남은 49,000개 전부를 10개
client에 IID로 분할한다. Seed 0에서는 client마다 각 class 490개, 총 4,900개를 갖는다.
Codec과 classifier는 remaining-client index만 재사용하며 target은 observer에서 제외한다.
Public/client 집합의 index, seed, class count와 overlap 부재를 각 run의
`split_manifest.json`에 기록하고, classifier를 붙이는 별도 run은 classifier state
hash도 기록한다.

등록 reconstruction-only config는 다음 두 개다.

- Pilot: `federated_cifar10_iid_vdeepjscc_standard_vib_49k_pilot.json`
- Main: `federated_cifar10_iid_vdeepjscc_standard_vib_49k_800rounds.json`

Pilot은 20 rounds와 evaluation interval 5를 사용하며 learning-rate decay를 적용하지
않는다. Main은 800 rounds, round 350 learning-rate decay, evaluation interval 20을
사용한다. 두 config 모두 sampled-posterior Monte Carlo 10회 평가를 primary로 둔다.

## 필수 그래프와 완료 조건

앞으로 pilot, smoke, ablation, 본 학습, unlearning audit을 포함한 모든 실험은 같은
`src/main.py` 실행에서 `figures/` 아래에 task에 맞는 그래프를 자동 생성한다. 그래프의
모든 점은 같은 run의 `metrics/` 아래 CSV 또는 JSON에서 다시 그릴 수 있어야 한다.
필수 그래프가 없으면 command가 정상 종료했더라도 완료된 실험으로 보지 않는다. Smoke
그래프는 artifact plumbing 확인용이며 논문 결과로 해석하지 않는다.

| 실험 종류 | 필수 그래프 |
| --- | --- |
| Reconstruction FL 학습 | global round별 total objective, reconstruction term, beta-weighted KL term과 train reconstruction quality; evaluation interval별 held-out RMSE-255와 PSNR |
| 독립 classifier FL 학습 | global round별 train/held-out CE와 accuracy; reconstruction/PSNR 지표는 넣지 않음 |
| Reconstruction federated unlearning | Original, Retrain, Unlearned 순서의 clean/erased PSNR·SSIM, retain FID, marker MPR/PUL, Runtime; S1 연속 projection/NCC 및 별도 보조 dFIL figure; iterative stage가 있으면 forgetting/repair loss |
| Classifier federated unlearning | Original, Retrain, Unlearned의 clean/target CE와 accuracy, ASR/MIA/BA 및 Runtime 비교; reconstruction/PSNR 지표는 넣지 않음 |
| Split 또는 channel ablation | client별 class count/proportion과 SNR별 metric curve; 비교 model의 순서와 축 범위를 가능한 한 동일하게 유지 |

기본 파일 이름은 reconstruction 학습에서
`figures/<split>_training_loss.png`와
`figures/<split>_training_performance.png`, classifier 학습에서
`figures/<split>_classification_training.png`를 사용한다. Unlearning은 여러 단위의
지표를 한 축에 섞지 않고 multi-panel `figures/unlearning_headline_comparison.png`와,
iterative optimization이 있으면 `figures/unlearning_optimization.png`를 남긴다.

Raw unsmoothed curve를 보존하고 smoothing은 window를 기록한 보조 overlay로만 허용한다.
모든 축에는 round/step, 단위, split, channel과 SNR, train 또는 held-out/test 여부를
명시한다. Final round와 실제 선택 checkpoint를 표시하고 선택 규칙을 metadata에
기록한다. 공식 CIFAR-10 test 결과를 본 뒤 유리한 round를 고르지 않으며, round budget은
사전에 고정한 validation 또는 held-out diagnostic curve로 판단한다.

현재 800 rounds는 등록 main budget이지 자동으로 충분하다고 가정하는 상수가 아니다.
800-round 적절성을 주장하려면 중간 held-out curve, 마지막 구간의 개선량, learning-rate
변경 지점을 함께 보여주고 사전에 정한 convergence rule을 보고해야 한다. 최종 checkpoint
한 점이나 train PSNR만으로 수렴을 주장하지 않는다.

## Reference Checkpoint Bank

Original FL model과 target client를 제외한 full-retraining model은 unlearning method와
hyperparameter가 바뀌어도 학습 조건이 같으면 동일하다. 따라서 완전히 같은
training scenario에서는 다음 세 state를 한 번만 학습하고 reference artifact로
동결한다.

- `initial.pt`
- `original.pt`
- `retrain_without_client_<target_id>.pt`

후속 unlearning run은 reference checkpoint를 load한 뒤 unlearning과 evaluation만 수행한다.
이로써 JU/CC epoch, repair loss weight, aggregation 방식 등을 바꾸는 실험에서
Original 800 rounds와 Retrain 800 rounds를 매번 반복하지 않는다.

### Reference reuse key

`model + seed`만 같다고 reuse하지 않는다. 다음 항목을 canonical JSON으로
직렬화해 scenario fingerprint를 만들고, 전체가 일치할 때만 reuse한다.

- codec architecture와 모든 codec parameter
- 별도 classifier를 사용하는 평가 scenario이면 classifier architecture, 학습 설정,
  clean-data index hash, state hash
- initial-state seed와 initial checkpoint hash
- dataset version, 정확한 client split index, training-pool index
- public-data 예약 index와 public-data seed
- split 종류와 parameter, client 수, client당 sample 수
- target client ID
- SCU backdoor protocol, poisoned local position, poison seed
- FL rounds, local epochs, batch size, optimizer, learning rate, aggregation
- client별 local optimizer state 유지 여부
- training augmentation version, crop padding, horizontal-flip probability
- reconstruction/KL loss weight와 classifier CE가 codec에 연결되지 않는다는 설정
- training channel, training SNR, deterministic option

기본 FL optimizer는 Adam이며, 표준 FedAvg 경계에 맞춰 각 client가 매 global round마다
새 optimizer state로 local update를 시작한다. 이 동작은
`federation.persist_client_optimizer_state=false`로 기록한다. Client별 Adam moment를
round 사이에 유지하는 설정은 명시적 ablation에서만 사용하며, 값이 다르면 reference
checkpoint를 재사용할 수 없는 별도 training scenario로 취급한다.

등록 standard-VIB reconstruction은 원 논문 조건을 명확히 비교하기 위해
`training.augmentation=none`을 사용한다. Crop/flip은 별도 augmentation ablation에서만
사용한다. SCU backdoor가 설정된 scenario도 corner trigger의 위치와 모양을 고정하기
위해 augmentation을 `none`으로 두며, backdoor와 crop/flip을 동시에 켜는 config는
허용하지 않는다.

IID convergence 진단의 reconstruction과 classification은 하나의 multi-task model로
학습하지 않는다. `task=reconstruction`은 reconstruction-only codec을 batch-mean
per-example pixel SSE와 batch-mean per-example latent KL 합으로 학습하고, 별도의
normalized per-pixel MSE에서 PSNR과 RMSE-255를 계산해 추적한다. `task=classification`은
별도 CIFAR-10 classifier를 원본 client 이미지와 CE로만 학습하고 CE, accuracy만 추적한다.
두 task는 동일한 49k client split을 독립적으로 사용할 수 있으며 CE gradient와 model
state를 공유하지 않는다. Frozen semantic observer는 FSCU/unlearning 평가 workflow에만
둔다.

Unlearning method, forgetting/repair epoch, CC weight 같은 unlearning-only 조건은 reference
fingerprint에 넣지 않고 각 child run의 config에만 기록한다.

### Storage and provenance

Reference 전용 output root도 일반 output 명명 규칙을 따른다.

```text
outputs/YYYY-MM-DD-Index-reference-vdeepjscc-<split>/
  <timestamp>_seed-<seed>/
    config.json
    environment.json
    split_manifest.json
    reference_manifest.json
    metrics/efficiency.json
    metrics/training_history_<phase>.csv
    metrics/performance_history_<phase>.csv
    figures/<phase>_<split>_training_loss.png
    figures/<phase>_<split>_training_performance.png
    checkpoints/initial.pt
    checkpoints/original.pt
    checkpoints/retrain_without_client_<target_id>.pt
```

여기서 `<phase>`는 `original` 또는 `retrain`이다. Classifier-only reference는 loss
figure 대신 같은 phase prefix를 붙인 CE/accuracy figure를 저장한다.

`reference_manifest.json`은 scenario fingerprint, checkpoint SHA-256, original/retrain 학습
runtime을 담는다. Reference artifact는 덮어쓰거나 update하지 않는다. 후속 run은
checkpoint를 복사하는 대신 `reference_source.json`에 reference 경로, fingerprint,
hash를 기록하고 load 전에 재검증한다. Reference 학습 곡선도 immutable artifact로
보존하며, child unlearning run은 이를 복사하지 않고 `reference_source.json`으로 출처를
추적한다.

2-class와 Dirichlet 0.1은 split manifest가 다르므로 각각 독립 reference를 사용한다.
서로 다른 seed, target client, public-data 예약, backdoor realization, training channel
조건도 reference를 공유하지 않는다.

### Runtime accounting

Reference를 처음 만들 때 original과 retrain wall time을 직접 측정해 저장한다.
후속 run의 speedup은 저장된 retrain time과 새로 측정한 online unlearning time을
비교한다. Checkpoint load time은 별도로 기록하고 retrain/unlearning algorithm
runtime에는 포함하지 않는다.

## Baselines

- Original model without unlearning
- Full retraining without target client
- Gradient-ascent federated unlearning
- FedEraser-style historical update subtraction
- SCU-style centralized adaptation, when centralized access is allowed for oracle comparison
- FSCU: target-client joint unlearning plus server-side public-data contrastive compensation
- FSCUv4: target-client joint unlearning 뒤 frozen Original teacher를 remaining-client
  local retained data에서만 호출하는 paired-channel shallow feature-map KD와 client-wise
  conflict-aware projection aggregation
- FedSCU-DistributedDecoderCC: public data 없이 remaining-client local decoder CC update를 FedAvg
- FedSCU-DistributedJointRepair-FedAvg: 삭제 representation 없이 remaining-client가 full codec을 local repair
- FedSCU-DistributedJointRepair-ConflictAware: JU 역방향 repair component를 제거한 뒤 집계
- Joint forgetting without distributed repair
- Distributed repair without conflict-aware aggregation
- Full proposed method

Variational DeepJSCC를 사용하는 seed 0 PubCC 실행 config는 다음과 같다.

- `federated_cifar10_fedosd_2class_vdeepjscc_scu_public_compensation.json`
- `federated_cifar10_dirichlet_01_vdeepjscc_scu_public_compensation.json`

두 config는 model, data budget, batch, round, channel, public-data 크기와 CC
hyperparameter를 같게 두고 split과 target client만 바꾼다.

현재 등록 FSCU 설정은 기존 JU 5 epoch와 CC 40 epoch의 총 budget을 유지하면서 5개
cycle로 나눈다. Canonical latent는 power-normalized posterior mean이고, erased
buffer는 매 JU cycle 뒤 stratified sample로 refresh한다. Public positive는 두 CIFAR-10
augmentation의 deterministic canonical latent다. Sequential, original/static/refresh
buffer, stochastic/deterministic positive와 JU 안정화 ablation은
`09-08-02-fscu-interleaved-canonical-latent-계획.md`를 따른다.

Full method를 추가하기 전 representation 가설 진단으로
`client_specific_representation_audit`를 사용한다. 동일한 current global state에서
target normal local model, target local JU model, short remaining-client proxy를 만들고
public posterior mean에서 local difference와 true retraining deletion direction을
비교한다. 이 audit가 실패하면 local difference 기반 synthetic negative refinement는
진행하지 않는다.

## Historical / supplementary metrics (not the current core contract)

아래는 이전 평가 체계의 기록이다. 현재 필수 지표는 아래의 ‘최신 핵심 평가 체계’이며,
MIA, semantic accuracy, output-to-Retrain 등을 다시 필수 지표로 취급하지 않는다.

- RMSE-255, PSNR, and SSIM on clean test data and target-client erased data under paired AWGN 20 dB
- Retain u-FID: remaining-client clean reconstruction 분포와 실제 clean retain input 분포 비교
- FID-to-Retrain: 같은 입력과 paired AWGN에서 얻은 retrain 복원 출력의 Inception
  pool3 특징 분포와 비교하며 clean test와 erased train을 별도로 계산한다. 낮을수록
  retrain 출력 분포에 가깝다. Ground-truth 기준 FID와 구분한다.
- Accuracy: 동일한 frozen clean classifier가 decoded clean test samples를 분류한 accuracy
- ASR: clean base-class test samples에 SCU trigger를 새로 삽입한 probe의 attack success rate
- MIA: class-matched reconstruction-loss attack의 ROC-AUC
- BA: target client의 실제 poisoned erased samples에 대한 backdoor accuracy
- Runtime: phase scope를 명시한 실제 wall-clock time과 full retraining 대비 speedup
- MS-SSIM
- LPIPS
- Client-level utility variance
- Performance under different SNR values

과거 headline suite는
`RMSE-255, PSNR, FID-to-Retrain, Accuracy, ASR, MIA, BA, Runtime`을 기록했다.
현재 이 파일은 legacy diagnostic으로 유지한다. `BA`는 backdoor accuracy를 뜻한다. MIA threshold
attack의 balanced accuracy는 필요할 때 `MIA balanced accuracy`라고 풀어 쓰며 `BA`로
줄이지 않는다.

`--algorithm FSCU` 실행은 언러닝이 끝난 직후 이 headline suite를 자동으로 계산해
같은 run의 `metrics/headline_metrics.csv`에 저장한다. 별도 audit 명령은 과거
checkpoint를 다시 평가할 때만 사용한다.

FID는 `metrics/retrain_fid.csv`, `metrics/retrain_fid_protocol.json`과
`figures/retrain_fid_comparison.png`도 같은 실행에서 자동 저장한다. Inception은
평가 전용 frozen feature extractor이고 codec objective/gradient에 포함하지 않는다.
SSIM은 원본 대비 및 retrain 출력 대비 RGB SSIM으로 구현되어 있다. MS-SSIM과 LPIPS는
아직 추가 평가 후보이다. FID 구현과 검증 방법은
[`09-15-01-retrain-fid-평가-구현.md`](09-15-01-retrain-fid-평가-구현.md)를 따른다.

출력 비교의 추가 지표는 `PSNR-to-Retrain`, `SSIM-to-Retrain`, 공통 frozen observer의
`class agreement`, `probability JS`, `logit MSE`다. Clean test와 erased train을 분리하고
Original-to-Retrain도 함께 보고한다. Class agreement는 accuracy의 일치가 아니라
동일 입력의 argmax 일치 비율이다. 현재 핵심 지표를 대체하거나 이 지표만으로
완전한 삭제를 주장하지 않는다. Observer 학습과 적용 명령, validation 선택 규칙은
[`09-22-01-remaining-client-observer-구현.md`](09-22-01-remaining-client-observer-구현.md)를 따른다.

기본 결과의 `rmse_255`, `psnr`, `fg_output`은 posterior mean을 power-normalize한 뒤
20 dB AWGN을 통과시켜 계산한다. 동일 image에서는 모든 checkpoint가 동일한 channel
noise를 사용한다. 기존 noiseless posterior-mean 값은 각각
`rmse_255_noiseless`, `psnr_noiseless`, `fg_output_noiseless`로만 보조 보고한다.
SNR sweep과 Rayleigh 평가는 기본 20 dB 결과에 추가되는 robustness 실험이다.

SCU와의 비교를 위해 다음 두 reconstruction 집합을 별도로 기록한다.

- `clean_rmse_255`, `clean_psnr_db`: 공식 CIFAR-10 test set 10,000장
- `erased_rmse_255`, `erased_psnr_db`: 삭제 client의 전체 local training data 4,900장

RMSE-255는 먼저 0--1 RGB 범위에서 sample, channel, height, width 전체의 normalized
MSE를 구한 다음 `255 * sqrt(MSE)`로 계산한다. 따라서 8-bit pixel scale에서 해석할 수
있고 batch size와 이미지 크기에 독립적이다. 내부 normalized MSE는 PSNR과 functional
gap 계산을 위해 artifact에 계속 저장하지만 headline reconstruction 지표로 사용하지
않는다. 등록 v3의 학습 reconstruction term은 sample별 pixel SSE를 batch에서 평균하므로
이 평가 MSE와 다른 양이다. SCU 공개 CIFAR 코드의 `MSELoss(size_average=False)`는 batch
전체 합이어서 batch size에 따라 값이 달라지므로 본 연구의 canonical reconstruction
지표로 쓰지 않는다.

Client-level FU의 성공 조건은 erased RMSE-255를 무조건 크게 만드는 것이 아니다. Shared
class와 semantic information 때문에 target client를 제외한 retrained model도 target
sample을 잘 복원할 수 있다. 따라서 clean/erased RMSE-255 모두 retrain 기준과 가까운지를
참고하고, 현재의 marker PUL과 dFIL 및 retain utility를 함께 해석한다.

### Reconstruction marker 두 평가 시나리오

앞으로 marker 평가는 둘 다 사용하되 서로 분리해 보고한다.

- `방식 1(가중치 오염 시나리오)`: clean target-client input을 marked output으로
  학습시켜 비정상 mapping을 codec 가중치에 저장하는
  `unconditional_output_watermark_v1`
- `방식 2(데이터 오염 시나리오)`: target-client input의 마커 영역은 검은 mask로
  가리고 target에만 marker를 두는 `masked_input_marker_reconstruction_v1`.
  평가에서도 masked probe를 넣으므로 marker 출력은 단순 pixel copy가 아니라
  학습된 target-client mapping을 뜻한다.

과거 keyed-output pilot은 폐기하며 방식 2라는 이름으로 재사용하지 않는다. 두 방식은
`origin`, `retrain_without_target`, `FSCUv4`만 비교한다. 상세 정의와
판정 규칙은 `10-01-01-reconstruction-marker-두-평가-시나리오.md`를 따른다.

### 최신 핵심 평가 체계

2026-11-02 합의에 따라 핵심 지표는 다음으로 고정한다. 앞의 역사적 headline 목록보다
이 절과 `selected_core_metrics.csv`를 우선한다.

1. Reconstruction utility: 입력 기준 `PSNR`, `SSIM`, 실제 retain image 기준 `FID`
2. Marker occurrence: `MPR (%)`와 양성 건수/held-out N (S1/S2 모두)
3. Marker removal: `PUL` (Original 검출이 0이면 undefined)
4. Efficiency: `Runtime` (metric 평가 시간 제외)

모든 보고는 Original, Retrain-without-target, Unlearned(FSCUv4) 순서로 고정하고,
clean/erased PSNR·SSIM과 FID를 세 모델 모두 표시한다. S1은 threshold 아래의 약한
잔류도 볼 수 있도록 연속 marker projection 강도와 NCC를 함께 보고한다. 현재 이는
고정 위치 평가와 S1/S2 whole-image template-bank 평가를 분리한다. 전역/outside 반응,
global MPR와 pixel-union coverage, raw-only calibration과 control FPR/TPR를 저장한다.
Local MPR v2는 raw clean 최대 반응 기준이며 과거 midpoint 기준 결과와 구분한다.
Amplitude/NCC는 같은 held-out 500장의 실제 측정값으로 표시하며 0/100점 환산은 하지 않는다.
임의 형태의 번짐이나 client 삭제를 보장한다고 주장하지 않는다. dFIL은 보조 입력 민감도 진단이다.
CKA는 사용하지 않는다. Client-ID probe, posterior gap, marker sensitivity와
FID/PSNR/SSIM-to-Retrain은 핵심 판정에서 제외한다. PUL은 두 marker 시나리오에서 같은
정의를 사용하되 frozen marker detector의 threshold를 codec 출력과 무관한 clean/marked
raw reference로 보정한다. FID는 remaining-client reconstruction과 실제 clean retain
input 분포를 비교한다. PSNR과 SSIM은 clean test와 erased target-client train을
분리해 보고한다. Runtime은 품질 지표와 별도의 효율성 정보로 계속 기록한다.

정확한 계산식, 방향, 파일명은

## Historical unlearning metric candidates

아래는 과거 후보 목록이며 현행 필수 지표가 아니다. IDI·CKA·client-ID·MIA를
핵심 지표로 사용하지 않는다. 현재 계산 정의와 구현 상태는
`10-22-01-dfil-core-metrics.md`가 기준이다.

- Primary: retrain functional equivalence on target-client and retained-client
  partitions under paired inputs and paired channel realizations
- Primary: unlearning efficiency, including wall time, computation, communication,
  and storage overhead
- Secondary: representation equivalence using CKA/SVCCA and latent
  client-identity leakage, interpreted by distance to retraining
- Erased-representation-buffer leakage, including membership inference and feasible inversion/reconstruction diagnostics
- Sanity check: SCU-compatible backdoor ASR, used only when the original model
  clearly separates from retraining
- Supplementary: membership inference attack on target-client samples

The detailed protocol is fixed in
[`09-03-03-평가지표와-scu-backdoor-프로토콜.md`](09-03-03-평가지표와-scu-backdoor-프로토콜.md).

## Channel Conditions

- AWGN
- Rayleigh fading
- Training and test SNR mismatch
- Multiple SNR values, such as 0, 5, 10, 15, 20 dB

## Data Conditions

- IID split
- Non-IID split using Dirichlet concentration
- Different numbers of clients
- Different target-client data ratios
- Single-client and sequential multi-client unlearning
- Public-data size and public/retained distribution mismatch
