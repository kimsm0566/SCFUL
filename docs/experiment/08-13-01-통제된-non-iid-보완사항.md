# 통제된 Non-IID Oracle Behavior 실험: 구현 전 보완 사항

## 목적과 적용 범위

이 문서는 `통제된 Non-IID Oracle Behavior` 실험 계획의 구현 전 보완
사항을 기록한다. 이 실험의 주목적은 target input을 의도적으로 나쁘게
reconstruct하도록 만드는 것이 아니라, unlearned codec이 target client를 제외하고
처음부터 재학습한 oracle codec과 얼마나 가까운지를 측정하는 것이다.

```text
M^G       = A(D^t union D^r)
M^{-t}    = A(D^r)
M^U_SCU   = U_SCU-style(M^G, D^t, D^r)
```

주 성공 기준은 `M^U_SCU`와 `M^{-t}`의 output/posterior functional gap이다.
Target reconstruction MSE 증가와 backdoor/client-marker 제거는 보조 진단으로만
해석한다.

이 단계의 학습은 pooled centralized training이다. 따라서 virtual client split은
**통제된 client-deletion distribution shift**를 정의하며, client 1--4의 분할은
이 중앙집중식 oracle 모델의 optimization 과정에는 영향을 주지 않는다. 동일 split
manifest는 후속 FedAvg/distributed repair 실험에서 재사용한다.

## 구현 전에 반드시 확정할 항목

### 1. SCU comparator의 정확한 이름과 목적식

새 구현은 legacy code의 완전 재현이 아니라, whole target client에 맞춘
**SCU-style centralized VAE adaptation**으로 표기한다. `src/SCU/`는 변경하지 않는다.

Legacy `VAE_unl_ss`의 VAE 형태는 target--retained latent similarity ratio 또는
retained teacher self-consistency를 직접 사용하지 않는다. 핵심 형태는 다음과 같다.

```math
L_forget = lambda_KL KL(q_U(z|x_t) || q_G(z|x_t))
           - lambda_rec MSE(x_hat_t, x_t),

L_retain = beta KL(q_U(z|x_r) || p(z)) + MSE(x_hat_r, x_r).
```

동적 가중치는 두 scalar loss의 크기에서 만들어진다.

```math
w_forget = |L_forget| / (|L_forget| + |L_retain| + epsilon),
w_retain = |L_retain| / (|L_forget| + |L_retain| + epsilon),

L_self-sharing = w_forget L_forget +
                  w_retain lambda_ss L_retain.
```

여기서 `q_G`는 freeze된 original codec posterior이며, 모든 teacher forward는
gradient 없이 계산한다. 실제 구현에서 다음을 config와 run log에 명시한다.

- `lambda_KL`, `lambda_rec`, `lambda_ss`, `beta`, `epsilon`
- `KL(q_U || q_G)`의 방향
- `scu_forget_only`가 정확히 `L_forget`만 쓰는지 여부
- optimizer를 원본 Adam state에서 이어가는지, 새 Adam state로 시작하는지

새 retained self-consistency, target--retained similarity, 또는 다른 regularizer를
추가하면 그것은 legacy SCU가 아니라 별도 `SCU-style + <term>` ablation으로 기록한다.

### 2. Codec의 채널 및 전력 제약

"10 dB AWGN"은 latent 송신 전력이 정해져야 재현 가능하다. Encoder output의
크기가 model마다 달라지면 동일한 standard-normal noise를 넣어도 model별 유효 SNR이
달라질 수 있다.

Codec은 training과 evaluation에 같은 power normalization을 포함한다.

```math
z_bar = sqrt(d) mu / (||mu||_2 + epsilon_power),
n ~ N(0, 10^{-SNR_dB/10} I),
z_channel = z_bar + n.
```

- `d`는 latent dimension이다.
- deterministic path는 `z_channel = z_bar`를 사용한다.
- channel-aware path는 sample/repetition별로 고정한 noise `n`을 모든 model에
  공통 적용한다.
- posterior sampling을 training에 쓸 경우 `z = mu + sigma * eps`를 먼저 만들고,
  그 뒤 같은 power-normalized AWGN channel을 적용한다.

Encoder/decoder hidden widths, activations, log-variance clamp 범위, power
normalization 위치, reconstruction loss reduction도 config에 명시한다. 이들은
architecture의 일부이며 구두 설명만으로 남기지 않는다.

### 3. Training-member와 held-out target probe의 분리

`D^t`에서 선택한 target probe는 original model에 실제로 기여한 training member를
측정한다는 장점이 있지만, sample memorization과 semantic-support removal을 분리하지
못한다. 다음 두 target audit set을 함께 만든다.

| Probe | Data source | 목적 |
| --- | --- | --- |
| `target_train_member` | `D^t` | 실제 삭제 대상 training sample에서의 deletion behavior |
| `target_heldout` | MNIST test set | target client가 없을 때의 normal generalization behavior |

두 audit set 모두 `shared_high`와 `target_specific` support group을 갖는다.

- `shared_high`: digit 3--6에서 각 digit당 동일 수를 추출한다. 256개 probe라면
  digit별 64개를 사용한다.
- `target_specific`: digit 1을 사용한다. `D^r`에 digit-1 training sample은 0개여야 한다.

Retained utility probe는 MNIST test의 label 1을 제외한 stratified 2,000개를 계속
사용한다. CSV record에는 index 충돌을 막기 위해 `dataset_split` (`mnist_train` 또는
`mnist_test`)과 `source_index`를 함께 저장한다.

### 4. Split의 완전성·균형성·manifest

`client_0`은 다음으로 고정한다.

```text
digit 3, 4, 5, 6: 각 1,500개  -> shared_high
digit 1 전체                    -> target_specific
```

나머지는 retained set이며 digit 1의 retained count는 반드시 0이다. Class별 shuffled
round-robin 분할에서는 class마다 시작 client를 회전해야 remainders가 한 client에
누적되지 않는다. 이 규칙으로 retained client 전체 크기 차이를 최대 1로 보장한다.

Manifest에는 최소한 다음을 쓴다.

- dataset name/version 및 transform
- global/split/probe seed
- 각 client index array와 SHA-256 digest
- support-group membership
- client별 label count와 total count
- coverage assertions: complete, mutually exclusive, retained digit-1 count 0

## Training 공정성과 stochasticity 통제

### 동일 initial state와 schedule

각 global seed마다 `initial.pt`를 한 번 저장하고, `original`과 `retrain`은 이
byte-identical weight state에서 시작한다. `scu_forget_only`와 `scu_self_sharing`은
완성된 `original` checkpoint에서 시작한다.

모든 model에 대해 다음의 별도 seed를 기록한다.

- initial model seed
- data-order sampler seed
- posterior-reparameterization seed
- channel-noise training seed
- evaluation-noise seed

"20 epochs"는 training algorithm `A`의 일부로 명시한다. Original과 retrain의
optimizer step 수는 data size 때문에 달라진다. 이는 epoch-based retraining oracle로는
정당하지만, 결과가 update budget 차이에 민감한지 확인하기 위해 후속 sensitivity에서
**compute-matched retrain** (original과 동일 optimizer step 수)을 추가하는 것이 좋다.

### Paired SCU batch exposure

Target/retained loader를 `zip`으로 pairing하면 epoch마다 target batch 수만큼만 retained
batch를 사용한다. 이는 partial compensation 설정으로 유효하지만 다음을 고정해야 한다.

- retained batch가 epoch마다 shuffle되어 새 subset을 보는지
- replacement sampling인지
- target 및 retained 각각의 총 example exposure와 optimizer step 수
- `scu_forget_only`와 `scu_self_sharing`의 update budget이 같은지

모든 값을 `config.json` 및 `run.log`에 저장한다.

### Seed-level uncertainty와 retraining noise floor

Run 내부의 sample bootstrap CI는 고정된 checkpoint의 sample variation만 나타낸다.
연구 결론은 최소 3개, 권장 5개의 global seed에 대해 보고한다.

각 seed에서 `D^r`로 train-order/channel seed만 다르게 한 추가 retrain replica를
한 번 학습하여 다음 noise floor를 기록한다.

```math
FG_retrain-noise = FG(M^{-t}_{a}, M^{-t}_{b}).
```

SCU-to-retrain gap은 이 stochastic retraining variability와 함께 해석한다. 최종
summary에는 다음을 분리한다.

- run 내 strata별 bootstrap CI
- global seed 간 mean/standard deviation 또는 CI
- retrain-retrain functional-gap noise floor

## Functional-gap evaluation 명세

각 model `m`에 대해 deterministic posterior-mean path와 `R=8`의 AWGN path를 평가한다.
Diagonal Gaussian posterior에서 latent gap은 전체 latent dimension으로 계산한다.

```math
FG_output^m(x) = mean((x_hat_m - x_hat_retrain)^2),
FG_mu^m(x) = mean((mu_m - mu_retrain)^2),

FG_latent^m(x) = 0.5 [KL(q_m || q_retrain) + KL(q_retrain || q_m)].
```

`logvar`는 KL 계산 전에 같은 명시적 범위로 clamp하여 numerical overflow를 피한다.
`retrain` row도 같은 schema로 저장하고 self-gap을 0으로 기록한다.

AWGN functional gap은 reconstruction 평균끼리 비교하지 않는다. 동일 noise draw `r`에
대해 먼저 gap을 계산하고, 그 값을 repetitions에 걸쳐 평균한다.

```math
FG_output_AWGN^m(x) =
(1/R) sum_{r=1}^R mean((x_hat_m^(r) - x_hat_retrain^(r))^2).
```

`MSE_input`도 동일하게 draw별 계산 뒤 평균한다. Posterior gap은 channel-independent
값이므로 두 evaluation condition에 중복 기록할 경우 이를 metadata에 명시한다.

`per_sample.csv`의 최소 columns는 다음과 같다.

```text
dataset_split, source_index, probe_partition, support_group,
model, evaluation_condition, channel_repetitions,
mse_input, fg_output, fg_mu, fg_latent
```

`predictions/probes.pt`에는 figure 재생성에 필요한 input, posterior mean/logvar,
posterior-mean reconstruction, AWGN reconstruction aggregate mean/standard deviation,
그리고 fixed noise-generation metadata를 저장한다.

## Figure와 결과 해석

Reconstruction grid는 fixed number의 `shared_high` 및 `target_specific` probe를 같은
수로 포함하고, posterior-mean output을 한 행에서 비교한다.

```text
input | original | retrain without target | SCU forget-only | SCU self-sharing
```

Latent figure의 첫 두 coordinate는 정성적 진단일 뿐 정량 결론에 쓰지 않는다. 같은
sample의 `original -> retrain`과 `SCU self-sharing -> retrain` 이동을 일부 arrow로
보이고, 전체 20 dimensions의 symmetric KL을 주 정량 지표로 사용한다.

해석은 support regime별 oracle behavior를 기준으로 한다.

- `shared_high`에서 original--retrain gap이 작고 SCU--retrain gap이 크면,
  SCU가 shared semantic을 과도하게 손상했거나 repair가 부족한 것이다.
- `target_specific`에서 original--retrain gap이 크고 SCU가 retrain에 가까우면,
  oracle-consistent deletion behavior다.
- target `MSE_input` 증가만으로 성공을 주장하지 않는다.
- retained utility가 retrain보다 나쁘면 target MSE와 무관하게 utility damage다.

이 중앙집중식 실험은 membership privacy, latent client-identity leakage, secure
aggregation, 또는 distributed repair의 효과를 직접 증명하지 않는다. 해당 주장은
후속 federated experiment에서 별도로 검증한다.

## 산출물 체크리스트

매 run은 기존 결과를 덮어쓰지 않는 directory에 다음을 남긴다.

```text
outputs/oracle_behavior/<UTC timestamp>_seed-<seed>/
  config.json
  environment.json
  split_manifest.json
  checkpoints/initial.pt
  checkpoints/original.pt
  checkpoints/retrain.pt
  checkpoints/scu_forget_only.pt
  checkpoints/scu_self_sharing.pt
  metrics/per_sample.csv
  metrics/summary.json
  predictions/probes.pt
  figures/reconstruction_grid.png
  figures/latent_comparison.png
  run.log
```

`environment.json`에는 Python/PyTorch/torchvision/CUDA/cuDNN version, selected device,
deterministic-algorithm setting, 그리고 Git revision을 기록한다. Top-level repository가
Git repository가 아닌 경우 그 사실도 명시하고, available nested source revision을 별도
기록한다.

구현 완료 전에는 CPU synthetic-data smoke test로 split, model shape, artifact schema,
CSV/JSON/checkpoint/figure 생성을 검증한다. 실제 MNIST run은 CUDA pilot에서 최소 한
seed로 end-to-end 수행한 뒤, 정식 multi-seed result를 생성한다.
