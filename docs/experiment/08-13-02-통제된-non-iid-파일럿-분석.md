# 통제된 Non-IID Oracle Behavior Pilot 분석 (seed 0)

## 요약

이 문서는 `outputs/oracle_behavior/20260813T120103Z_seed-0/`의 MNIST CUDA pilot을 분석한다. 이 run은 full-data original, target client를 제외한 retraining oracle, retraining replica, SCU-style forget-only, SCU-style self-sharing을 같은 target input에 대해 비교했다.

이번 pilot에서 얻은 가장 중요한 결론은 다음과 같다.

1. **Target reconstruction MSE 증가만으로 forgetting 성공을 판단하면 안 된다.** Forget-only는 target과 retained sample 모두를 파괴했다.
2. **Target-specific semantic도 retraining oracle에서 완전히 사라지지 않는다.** Digit 1을 retained training data에서 완전히 제거했어도 retrain model은 target digit 1을 일부 복원했다. 따라서 target output을 의도적으로 무너뜨리는 것은 retrain-equivalent behavior가 아니다.
3. **Client semantic distribution을 단일 diagonal Gaussian `(mu_k, sigma_k^2)`로 충분하다고 가정할 근거가 없다.** 모든 client에서 단일 Gaussian MMD point estimate가 empirical posterior sampling noise보다 컸고, label-mixture diagnostic도 일관되게 더 좋은 NLL을 보였다. 다만 단일 seed의 bootstrap CI가 1을 포함하므로 정식 결론은 multi-seed 재검증 뒤에 내려야 한다.

이 실험은 pooled centralized oracle study다. `scu_self_sharing`은 retained raw data에 직접 접근하는 centralized comparator이며, federated/distributed repair 방법이 아니다.

### Codec 및 학습 설정

| 항목 | 값 |
| --- | --- |
| Codec | MLP encoder `784 -> 400 -> 2 x 20`, MLP decoder `20 -> 400 -> 784` |
| Posterior | Diagonal Gaussian, `logvar` clamp `[-8, 4]` |
| Channel | sampled posterior latent를 power-normalize한 AWGN, train/eval SNR 10 dB |
| Power normalization | `sqrt(d) z / (||z||_2 + 1e-8)` |
| Original / retrain / replica | Adam, learning rate `1e-4`, batch size 128, 20 epoch, VAE beta `1e-4` |
| Original update | 9,380 step, 1,200,000 sample exposure |
| Retrain / replica update | 각각 7,400 step, 945,160 sample exposure |
| SCU variant | target update 2,000 step, target/retained 각각 254,840 sample exposure |
| AWGN evaluation | 동일 probe/repetition noise를 모든 model에 공유, 8회 평균 |

Retrain과 retrain replica는 byte-identical `initial.pt`에서 시작했다. Replica는 data order, posterior reparameterization, channel noise seed만 다르며 retraining stochasticity noise floor를 측정한다.

## 평가 지표

각 model `m`에 대해 retrain oracle을 기준으로 다음을 계산했다.

```text
MSE_input^m = mean((x - x_hat_m)^2)
FG_output^m = mean((x_hat_m - x_hat_retrain)^2)
FG_mu^m = mean((mu_m - mu_retrain)^2)
FG_latent^m = 0.5 [KL(q_m || q_retrain) + KL(q_retrain || q_m)]
```

`MSE_input`은 보조 지표다. 이 분석의 주 지표는 `FG_output`과, 안정성이 확인된 뒤의 `FG_latent`다.

### 해석

#### 1. Shared semantic에서는 original과 retrain이 이미 가깝다

`shared_high` target member에서 original의 output gap은 `0.001167`이다. Target client를 제거해도 retained client가 digit 3--6을 충분히 갖고 있으므로, retraining oracle은 같은 sample을 여전히 잘 복원한다. 따라서 이 group에서 target MSE를 키우는 것은 올바른 deletion behavior가 아니다.

`scu_self_sharing`의 output gap은 `0.001277`로 original보다 약간 크다. 즉 이 pilot에서는 shared semantic을 보호하는 방향으로 retrain oracle에 더 가까워졌다고 보기 어렵다.

#### 2. Target-specific semantic도 oracle에서 완전히 사라지지 않는다

Digit 1 training sample은 retained data에 0개지만, target-specific group의 retrain MSE는 `0.011910`이다. Original의 `0.004358`보다는 나빠졌지만 완전한 붕괴는 아니다. MNIST digit structure에서 다른 digit으로부터 얻은 stroke-level knowledge가 digit 1 복원에 일반화된 것으로 해석할 수 있다.

이 결과는 “target client만 가진 semantic이면 unlearned model이 반드시 복원하지 못해야 한다”는 기준도 지나치게 강하다는 점을 보여준다. 올바른 기준은 여전히 retraining oracle이다.

`scu_self_sharing`은 output gap을 original의 `0.005647`에서 `0.003753`으로 줄였다. 즉 target-specific group에서는 oracle 쪽으로 일부 이동했다. 그러나 MSE는 `0.004921`로 retrain MSE보다 훨씬 낮다. Self-sharing이 아직 original의 복원력을 많이 유지한다는 뜻이며, 완전한 retrain equivalence는 아니다.

#### 3. Forget-only는 정확히 피해야 할 실패 형태다

Forget-only의 target MSE는 `0.446`--`0.513`으로 매우 크지만, retained held-out MSE도 `0.436`이다. Output gap도 target/retained에서 약 `0.41`--`0.47`로 매우 크다. 따라서 target을 망가뜨렸다는 사실은 unlearning 성공이 아니라 codec 전체 손상이다.

이는 distributed retain repair가 필요한 이유를 보여주는 직접적인 control이다. 다만 이번 self-sharing은 centralized retained-data 접근을 사용하므로, 후속 방법은 이 repair를 raw-data centralization 없이 수행해야 한다.

#### 4. AWGN 10 dB에서도 같은 경향이다

Target member의 AWGN 10 dB output gap은 다음과 같다.

| Group | Original | SCU forget-only | SCU self-sharing |
| --- | ---: | ---: | ---: |
| shared_high | 0.001963 | 0.420730 | 0.002081 |
| target_specific | 0.006299 | 0.471642 | 0.004376 |

Channel noise를 넣어도 forget-only의 과도한 손상과 self-sharing의 부분적 oracle 접근이라는 방향은 유지된다.

#### 5. Latent symmetric KL은 아직 주 결론 지표로 쓰기 어렵다

Output gap은 retrain replica의 noise floor가 `0.000252`--`0.000485`인 반면, latent symmetric KL noise floor는 `32.588`--`52.846`이다. Original/SCU의 latent KL은 약 `99`--`101`이지만, retrain 자체도 stochastic training seed에 따라 큰 posterior 차이를 보인다.

따라서 이 pilot에서는 output functional gap을 우선 지표로 사용한다. Latent conclusion을 강하게 주장하려면 seed별 retrain replica를 여러 개 추가하고, posterior coordinate alignment 또는 distribution-level latent comparison을 보완해야 한다.

## Client semantic distribution: 단일 `(mu_k, sigma_k^2)` 충분성 진단

각 client에서 original codec의 aggregated posterior를 80% fitting set으로 moment-match했다.

```text
mu_k = mean_i(mu_i)
sigma_k^2 = mean_i(exp(logvar_i) + mu_i^2) - mu_k^2
```

나머지 20%에서 empirical posterior sample과 moment-matched single Gaussian sample을 비교했다. `mmd_excess_ratio`는 single-Gaussian MMD를 empirical posterior의 두 독립 draw MMD로 나눈 값이다. Label-mixture는 method가 아니라 client 내부 semantic multimodality를 드러내는 diagnostic upper reference다.

| Client | MMD single | MMD empirical noise | Excess ratio | Ratio bootstrap 95% CI | 평균 절댓값 off-diagonal corr. | 평균 절댓값 excess kurtosis | Label-mixture NLL gain/dim |
| --- | ---: | ---: | ---: | --- | ---: | ---: | ---: |
| client_0 target | 0.004717 | 0.001646 | 2.866 | [0.933, 3.120] | 0.129 | 0.756 | 0.1248 |
| client_1 | 0.001972 | 0.000988 | 1.995 | [0.785, 2.170] | 0.075 | 0.214 | 0.0530 |
| client_2 | 0.003046 | 0.001190 | 2.560 | [0.895, 2.551] | 0.072 | 0.171 | 0.0495 |
| client_3 | 0.001831 | 0.000860 | 2.130 | [0.778, 2.323] | 0.082 | 0.265 | 0.0595 |
| client_4 | 0.001873 | 0.000752 | 2.492 | [0.724, 2.228] | 0.076 | 0.217 | 0.0552 |

### 해석

- 모든 client에서 point estimate는 `mmd_excess_ratio > 1`이다. 즉 단일 Gaussian의 distribution gap이 같은 empirical posterior의 sampling noise보다 크다.
- 모든 client에서 off-diagonal correlation과 non-zero excess kurtosis가 관찰된다. Diagonal Gaussian은 이 dependence와 tail structure를 표현하지 못한다.
- 모든 client에서 label-mixture가 single Gaussian보다 좋은 held-out NLL을 보인다. 특히 digit 1과 digit 3--6이 함께 있는 target `client_0`의 gain이 가장 크다.
- 그러나 각 client의 bootstrap CI는 1을 포함한다. 이는 **한 run의 within-client resampling만으로는 단일 Gaussian 부적합을 확정하기에 부족하다**는 뜻이다. 이 CI는 global seed variation을 포함하지 않는다.

따라서 현재의 안전한 판단은 다음과 같다.

> 단일 `(mu_k, sigma_k^2)`를 client semantic distribution의 기본 표현으로 채택할 실증 근거는 아직 없다. 다만 모든 point estimate와 mixture diagnostic은 더 풍부한 representation의 필요성을 일관되게 시사한다.

## 제한 사항

1. Global seed 0 하나만 사용했다. Bootstrap CI는 sample variation이지 seed-level uncertainty가 아니다.
2. Retrain replica가 각 seed에서 하나뿐이다. Latent noise floor estimate의 신뢰도가 낮다.
3. Pooled centralized training과 centralized SCU-style comparator만 다뤘다. FedAvg, distributed repair, conflict-aware aggregation은 아직 평가하지 않았다.
4. MNIST, 20-dimensional latent, AWGN 10 dB만 다뤘다. Rayleigh, SNR mismatch, CIFAR 계열, IID/non-IID sweep은 후속 범위다.
5. `scu_self_sharing`은 legacy SCU backdoor script의 완전 재현이 아니라 명세된 whole-client SCU-style VAE adaptation이다.
6. `FG_latent`는 posterior coordinate의 stochastic drift 영향을 크게 받는다. 현재 결과만으로 latent semantic removal을 정량 결론으로 주장하면 안 된다.

## 다음 실험 우선순위

1. 동일 config에서 global seed 1, 2를 추가하고, seed별 retrain replica를 최소 2개로 늘린다.
2. 각 seed에서 `mmd_excess_ratio`, mixture NLL gain, output functional gap을 aggregate해 seed-level mean/CI를 보고한다.
3. Client summary 후보를 동일 communication budget에서 비교한다: single diagonal Gaussian, multi-prototype/mixture, low-rank covariance.
4. Shared-high group에서 SCU가 original보다 oracle에 가까워지지 못한 원인을 분리한다. Forgetting direction과 retained repair direction의 gradient conflict를 측정한다.
5. Pooled repair를 remaining client-local repair로 바꾸고, conflict-aware aggregation을 추가한다. 이 단계에서 raw retained data가 server에 전달되지 않도록 한다.
