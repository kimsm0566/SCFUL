# Reconstruction federated unlearning 핵심 평가 지표

## 최종 선택

핵심 지표는 기존 논문에서 사용된 지표만 남긴다.

| 평가 위치 | 핵심 지표 |
| --- | --- |
| Encoder representation | IDI |
| Decoded output | PUL, FID, PSNR, SSIM |

CKA는 사용하지 않는다. Client-ID probe, latent mean/posterior gap,
latent/output marker sensitivity, marker projection, FID/PSNR/SSIM-to-Retrain도
핵심 판정 지표에서 제외한다. 기존 artifact를 재현해야 할 때 보조 진단으로 남길 수는
있지만 논문의 주 결과표에는 넣지 않는다.

## 공통 비교 원칙

모든 지표는 `Original`, `Retrain-without-target`, `Unlearned`에 같은 평가 데이터와
같은 channel 조건을 적용한다. 목표는 다음과 같다.

```text
Unlearned의 삭제 관련 행동 -> Retrain-without-target에 가까움
Unlearned의 retained reconstruction utility -> 가능한 한 보존
```

PSNR과 SSIM은 clean CIFAR-10 test와 target-client erased train을 분리해 보고한다.
FID는 remaining-client clean reconstruction과 실제 remaining-client clean input 사이에서
계산한다. PUL은 marker protocol이 정의된 실험에서만 계산한다.

## 1. Encoder: IDI

IDI는 각 encoder layer의 feature와 `forget/retain membership` 사이 mutual information을
InfoNCE critic으로 추정한 뒤, Retrain을 기준으로 정규화한다.

```text
각 layer 정보량 = MI(encoder feature, forget/retain membership)
정보 차이 = 모든 선택 layer에서 model 정보량 - Retrain 정보량
IDI = model 정보 차이 / Original 정보 차이
```

- `Retrain IDI = 0`
- `Original IDI = 1`
- `Unlearned IDI`는 0에 가까울수록 Retrain encoder와 비슷한 삭제 상태다.

Target과 retain 표본의 semantic-class 구성이 다르면 IDI가 단순 class 차이를 client
정보로 오인할 수 있다. 따라서 target/retain 표본을 class-matched하게 구성하고,
critic 학습용과 held-out 평가용 표본을 분리한다. Critic 초기값을 바꾼 반복 실험의
평균과 표준오차를 저장한다.

IDI는 empirical information estimator이며 정보가 완전히 사라졌다는 수학적 증명은
아니다. 다만 이 프로젝트에서 encoder intermediate representation을 직접 검사하는
유일한 핵심 지표로 사용한다.

## 2. Decoded output: PUL

PUL은 Original에서 나타나던 삭제 대상 출력이 model에서 얼마나 줄었는지를 백분율로
나타낸다.

```text
PUL = 100 * (Original positive count - model positive count)
      / Original positive count
```

- `Original PUL = 0%`
- 삭제 대상 출력이 모두 사라지면 `PUL = 100%`
- 높을수록 삭제 대상 출력 빈도가 더 많이 감소했다.

본 프로젝트에서는 삭제 대상을 marker-positive reconstruction으로 둔다. Marker
검출기는 알려진 보라-초록 pattern에 대한 frozen detector이며, threshold는 codec
출력을 보지 않고 clean raw image와 marked raw image로만 먼저 보정한다. Original,
Retrain, Unlearned에 완전히 같은 detector와 threshold를 적용한다. Original에서
positive가 거의 검출되지 않으면 분모가 성립하지 않으므로 해당 run의 PUL은 무효다.

## 3. Decoded output: FID

FID는 frozen `pytorch-fid` Inception pool3 feature의 평균과 공분산을 사용해 두 이미지
분포의 거리를 계산한다. 이 프로젝트의 핵심 FID reference는 Retrain 출력이 아니라
실제 remaining-client clean input이다.

```text
candidate = remaining-client clean reconstruction
reference = 같은 subset의 real remaining-client clean input
```

CSV field는 `retain_fid_to_real`이다. 기존 artifact의 `retain_ufid`와 같은 계산이며,
이제 주 결과에서는 일반적인 `retain FID`로 표기한다. 낮을수록 retained reconstruction
분포가 실제 retain image 분포에 가깝다. Retrain self-FID를 0으로 만드는
`FID-to-Retrain`은 핵심에서 제외한다.

## 4. Decoded output: PSNR과 SSIM

PSNR과 SSIM은 각 reconstruction을 해당 ground-truth input과 비교한다.

- PSNR: 높을수록 pixel reconstruction이 좋다.
- SSIM: 높을수록 밝기, 대비, 구조가 잘 보존된다.

두 지표 모두 clean test와 erased target-client train을 따로 보고한다. Erased 성능을
무조건 낮추는 것이 성공은 아니다. Remaining clients에도 비슷한 이미지 정보가 있으면
Retrain도 erased sample을 잘 복원할 수 있기 때문이다. 따라서 Original, Retrain,
Unlearned 세 값을 함께 제시한다.

## 5. 해석상 주의

PUL, FID, PSNR, SSIM은 decoder parameter만 분리해서 검사하는 지표가 아니다. 실제로는
`input -> encoder -> channel -> decoder -> reconstruction` 전체 경로의 최종 출력을
평가한다. 이들을 논문에서 `output-side metrics`로 부르고, encoder 내부는 IDI로 따로
검사한다.

PUL 하나만으로 삭제를 주장하지 않는다. PUL은 marker 삭제를, FID/PSNR/SSIM은 retained
output utility를, IDI는 encoder representation의 target/retain information difference를
각각 보완한다.
