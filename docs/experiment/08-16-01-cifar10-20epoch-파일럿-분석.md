# CIFAR-10 통제된 삭제 행동 비교 분석 (seed 0)

> 이 문서는 20 epoch 파일럿 결과다. 충분한 학습 길이에서 다시 실행한 결과는 [200 epoch 분석](08-16-02-cifar10-200epoch-분석.md)을 기준으로 본다.

이 문서는 `outputs/cifar10_behavior/20260816T110820Z_seed-0/`의 CUDA 실행 결과를 기록한다. MNIST와 같은 방식으로 삭제 전 모델, 삭제 대상을 제외하고 처음부터 학습한 기준 모델, 기준 모델의 재학습 변동성 확인용 복제본, SCU forget-only, SCU self-sharing을 비교했다.

## 핵심 결론

1. SCU self-sharing의 출력은 삭제 대상 제외 재학습 기준 모델에 매우 가깝다. 다만 그 차이는 재학습 복제본 간 차이와 같은 규모이므로, seed 0 하나만으로 self-sharing이 기준 모델보다 더 낫다고 주장할 수는 없다.
2. Forget-only는 과도한 파괴를 일으킨다. 출력 functional gap이 약 `0.33--0.37`인 반면 재학습 변동성은 약 `0.0008--0.0021`이다. Target MSE를 크게 만드는 것은 올바른 삭제 행동의 증거가 아니다.
3. CIFAR-10에서도 target-specific class를 학습에서 완전히 제외한 기준 모델은 해당 class를 완전히 잃지 않는다. 따라서 자동차 이미지를 전혀 복원하지 못하게 하는 것을 삭제 성공으로 정의하면 안 된다.
4. 이 실험의 self-sharing은 retained raw data를 직접 쓰는 중앙집중식 비교 방법이다. 분산 repair나 제안 방법의 성능을 나타내지 않는다.

## 설정

| 항목 | 값 |
| --- | --- |
| Dataset | torchvision CIFAR-10, `ToTensor`, 32x32 RGB |
| Channel | power-normalized latent + AWGN 10 dB |
| Codec | Conv encoder/ConvTranspose decoder, latent 64, base channel 32 |
| Global seed | 0 |
| Optimizer | 새 Adam, learning rate `1e-4` |
| Original / 재학습 | 20 epoch, batch 128, VAE beta `1e-4` |
| SCU 두 변형 | 20 epoch, batch 128, `lambda_KL=1`, `lambda_rec=0.1`, `lambda_ss=1` |
| 평가 | posterior mean 및 같은 AWGN draw 8회, bootstrap 1,000회 |

Target client(`client_0`)는 shared class인 cat(3), deer(4), dog(5), frog(6)을 각각 1,500개씩 가지며, target-specific class인 automobile(1)은 5,000개 전체를 가진다. 따라서 target client는 총 11,000개다. Retained client 4명은 각각 9,750개이며 automobile training sample은 0개다. Manifest의 complete coverage, mutual exclusion, retained target-specific count 및 retained size balance assertion은 모두 통과했다.

## 학습량

| 모델 | Step | Sample exposure |
| --- | ---: | ---: |
| 삭제 전 모델 | 7,820 | 1,000,000 |
| 삭제 대상 제외 재학습 | 6,100 | 780,000 |
| 재학습 복제본 | 6,100 | 780,000 |
| SCU forget-only | 1,720 | target 220,000 / retained 220,160 |
| SCU self-sharing | 1,720 | target 220,000 / retained 220,160 |

삭제 대상 제외 재학습과 복제본은 byte-identical initial checkpoint에서 시작했다. Data order, posterior reparameterization, channel noise seed만 달라 재학습 자체의 stochasticity를 측정한다.

## Output functional gap

아래 `FG_output`은 같은 input에서 기준 모델의 reconstruction과의 sample MSE다. `retrain_replica`는 기준 모델을 다시 학습했을 때의 변동성이다.

### Posterior-mean 경로

| Probe | Original | 재학습 복제본 | SCU forget-only | SCU self-sharing |
| --- | ---: | ---: | ---: | ---: |
| target member / shared_high | 0.000765 | 0.000831 | 0.365190 | 0.000719 |
| target member / target_specific | 0.001019 | 0.000854 | 0.350576 | 0.000882 |
| target held-out / shared_high | 0.000782 | 0.000847 | 0.352104 | 0.000740 |
| target held-out / target_specific | 0.001003 | 0.000841 | 0.362190 | 0.000875 |
| retained held-out | 0.000796 | 0.000810 | 0.327851 | 0.000735 |

Self-sharing의 gap은 shared-high와 retained probe에서 재학습 변동성의 `0.87--0.91`배, target-specific probe에서는 `1.03--1.04`배다. 즉 output 관점에서는 기준 모델과 구분하기 어려운 범위까지 왔지만, 단일 복제본만으로 차이가 없다고 단정할 수는 없다.

### AWGN 10 dB 경로

| Probe | 재학습 복제본 | SCU forget-only | SCU self-sharing |
| --- | ---: | ---: | ---: |
| target member / shared_high | 0.001800 | 0.367941 | 0.001610 |
| target member / target_specific | 0.002071 | 0.353065 | 0.002087 |
| target held-out / shared_high | 0.001865 | 0.354564 | 0.001704 |
| target held-out / target_specific | 0.002069 | 0.364235 | 0.002056 |
| retained held-out | 0.001837 | 0.330216 | 0.001707 |

AWGN에서도 같은 방향이 유지된다. Self-sharing은 재학습 변동성과 거의 같은 출력 차이를 보이고, forget-only는 channel noise가 있어도 복구되지 않는 큰 손상을 만든다.

## Input reconstruction MSE 해석

Target training member에서 shared-high의 기준 모델 MSE는 `0.012325`, target-specific의 기준 모델 MSE는 `0.018339`였다. 삭제 전 모델은 각각 `0.011694`, `0.017052`이고 self-sharing은 `0.011776`, `0.017481`이었다.

Automobile을 retained training data에서 완전히 뺐어도 기준 모델의 자동차 재구성은 단지 악화되었을 뿐 사라지지 않았다. 다른 class에서 얻은 색·배경·물체 윤곽 지식이 일부 일반화된 결과로 해석할 수 있다. 따라서 self-sharing의 target MSE가 아주 크지 않다는 이유만으로 삭제 실패라고 볼 수 없다.

반대로 forget-only의 target MSE는 약 `0.36--0.37`로 급증하지만 retained MSE도 `0.337670`까지 붕괴한다. 이 결과는 target reconstruction 악화만을 주 성공 지표로 쓰면 안 된다는 점을 직접 보여 준다.

## Posterior 지표의 주의점

64차원 symmetric KL은 target member shared-high에서 original `147.505`, self-sharing `147.708`, 재학습 복제본 `154.710`처럼 모두 큰 값이다. Target-specific에서도 self-sharing `183.547`, 복제본 `192.710`이다.

재학습을 두 번 해도 posterior coordinate가 크게 달라진다는 뜻이므로, 이 single seed 결과에서 latent symmetric KL만으로 모델 간 우열이나 semantic deletion을 강하게 주장할 수 없다. 이 run에서는 paired output functional gap을 우선 지표로 해석하고, posterior는 multi-seed 분포 수준 분석이나 alignment 보완 뒤에 사용해야 한다.

## Client semantic distribution을 단일 `(mu_k, sigma_k^2)`로 표현해도 되는가

Original codec posterior를 client별 80% fitting split에서 diagonal Gaussian으로 moment matching한 뒤 나머지 20%에서 평가했다.

| Client | MMD excess ratio | 95% bootstrap CI | mean absolute off-diagonal correlation | mean absolute excess kurtosis | label-mixture NLL gain / dim |
| --- | ---: | --- | ---: | ---: | ---: |
| client_0 | 1.664 | [0.835, 1.767] | 0.057 | 0.205 | 0.0078 |
| client_1 | 1.836 | [0.846, 1.753] | 0.057 | 0.261 | 0.0121 |
| client_2 | 1.719 | [0.845, 1.791] | 0.054 | 0.218 | 0.0108 |
| client_3 | 1.570 | [0.816, 1.539] | 0.057 | 0.238 | 0.0112 |
| client_4 | 1.590 | [0.840, 1.689] | 0.056 | 0.273 | 0.0125 |

MMD excess ratio는 모든 client에서 1보다 크지만, 현재 bootstrap CI는 1을 포함한다. Off-diagonal correlation은 작지만 0은 아니고, excess kurtosis와 label-mixture NLL gain도 존재한다. 따라서 단일 diagonal Gaussian은 첫 번째 근사나 통신량이 작은 summary로는 사용할 수 있지만, client semantic distribution의 충분한 표현이라고 결론 내릴 수는 없다.

후속 실험에서는 단일 summary와 label-conditioned mixture 혹은 저차원 mixture의 repair/aggregation 성능 및 통신량을 같은 조건에서 비교해야 한다.

## 정성 결과와 한계

`figures/reconstruction_grid.png`에서 original, 삭제 대상 제외 재학습, self-sharing은 모두 CIFAR-10의 저주파 색·형태는 유지하지만 세부 texture는 흐리다. Forget-only 열은 거의 균일한 밝은 출력으로 붕괴한다. 이는 정량 결과와 일치한다.

- global seed 0 하나만 실행했다. 최소 3개, 권장 5개 seed가 필요하다.
- CIFAR-10 reconstruction 자체가 아직 흐리다. 더 큰 codec이나 더 긴 학습이 absolute reconstruction 품질을 개선하는지 별도로 점검해야 한다.
- 이 단계는 pooled centralized comparison이다. Membership inference, latent client-identity leakage, Rayleigh fading, SNR mismatch, 실제 federated repair는 아직 평가하지 않았다.
- Self-sharing은 retained raw data를 직접 사용하므로, 이후 방법에서는 이를 retained client의 local repair와 conflict-aware aggregation으로 대체해야 한다.
