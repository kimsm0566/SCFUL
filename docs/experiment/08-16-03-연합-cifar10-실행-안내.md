# 균등 데이터량 Non-IID CIFAR-10 연합 삭제 실험

## 목적

10개 client가 재구성 semantic codec을 함께 학습한 뒤, `client_0`의 전체
학습 기여를 제거한다. 각 client의 데이터 수는 같게 유지하고, semantic
distribution의 차이만 Dirichlet label skew로 만든다.

성공 기준은 target reconstruction을 임의로 나쁘게 만드는 것이 아니다.
`client_0`을 처음부터 제외하고 연합 재학습한 기준 model과, 삭제 후 model의
reconstruction 및 posterior behavior가 얼마나 가까운지를 본다.

## 데이터 분할

기본 config는 CIFAR-10 train 50,000개를 전부 사용한다.

```text
client 수                    10
client당 train sample        정확히 5,000개
class당 전체 train sample    정확히 5,000개
label skew                   Dirichlet alpha = 0.1
삭제 대상                    client_0 전체 5,000개
```

분할은 `10 x 10` client-class allocation matrix를 만든다. 각 행의 합은
5,000이고 각 열의 합은 5,000이다. 따라서 데이터 수 불균형 없이 class
composition만 client마다 다르다. 정확히 같은 client 크기를 강제해야 하므로,
독립적인 표준 Dirichlet draw를 그대로 쓰지는 않는다. 먼저 각 client-class
cell에서 `Gamma(alpha=0.1)` weight를 뽑고, 행·열 합 제약을 반복 scaling한 뒤
정수 allocation으로 반올림한다. 즉 이 실험의 정확한 명칭은
**균등 client 크기 제약 Dirichlet 기반 label skew**다.

Split은 CLI의 global `--seed`와 config의 `split.seed` offset을 함께 사용한다.
둘을 같게 두면 동일한 client-class allocation을 재현할 수 있다.

## 비교 model

```text
original
  10개 client의 FedAvg reconstruction training 결과

retrain_without_client_0
  client_0을 제외한 9개 client로 initial checkpoint부터 다시 학습한 기준 model

joint_forgetting
  client_0이 삭제 직전에 자신의 data만으로 encoder와 decoder를 함께 forgetting한 model

naive_repair
  joint_forgetting 뒤 9개 retained client가 local repair하고 일반 FedAvg로 집계한 model

conflict_aware_repair
  naive_repair와 같지만, forgetting 방향을 되돌리는 repair update 성분을 server가 제거한 model
```

Server는 retained raw data를 받지 않는다. 각 retained client는 자신의 local
data로만 repair한 뒤 model update와 scalar loss만 server로 보낸다.

## 기본 실행

컨테이너 안에서 server 1개와 client 10개, 총 11개 MPI process를 실행한다.

```bash
cd /workspace
mpirun --allow-run-as-root -np 11 python src/main.py \
  --experiment federated_deletion \
  --config src/configs/federated_cifar10_dirichlet_01.json \
  --seed 0 \
  --output-root outputs/federated_cifar10_dirichlet_01
```

기본 학습량은 original과 삭제 대상 제외 재학습이 각각 200 global rounds,
local epoch 1이다. client_0 forgetting은 200 epochs이며, naive/conflict-aware
repair는 각각 20 rounds다. Channel은 power-normalized AWGN 10 dB를 쓴다.

작은 MPI protocol 확인에는 다음 smoke config를 쓴다.

```bash
mpirun --allow-run-as-root -np 3 python src/main.py \
  --experiment federated_deletion \
  --config src/configs/federated_cifar10_smoke.json \
  --seed 0 \
  --output-root outputs/federated_smoke
```

## 산출물

각 run은 기존 결과를 덮어쓰지 않는 UTC timestamp directory에 저장된다.

```text
outputs/federated_cifar10_dirichlet_01/<timestamp>_seed-<seed>/
  config.json
  environment.json
  split_manifest.json
  checkpoints/
    initial.pt
    original.pt
    retrain_without_client_0.pt
    joint_forgetting.pt
    naive_repair.pt
    conflict_aware_repair.pt
  metrics/
    summary.json
    per_class.csv
    per_client.csv
  run.log
```

`summary.json`의 `fg_output`, `fg_mu`, `fg_latent`는 각각 재학습 기준 model과의
reconstruction output, posterior mean, symmetric posterior KL 차이다. 값이 작을수록
삭제 대상 제외 재학습 behavior에 가깝다.
