# FedOSD 호환 SCU 세 모델 실험 구현 계획

> **에이전트 작업자용:** 각 작업은 먼저 실패하는 테스트를 작성하고, 최소 구현과 검증을 마친 뒤 다음 작업으로 진행한다.

**목표:** FedOSD의 CIFAR-10 balanced pathological non-IID 분할을 재현하고, 200 라운드 original FL·client_0 제외 재학습·SCU식 client_0 forgetting의 세 codec을 공정하게 비교한다.

**구조:** `data.py`가 FedOSD의 `N=10`, `NC=2`, `balance=True` class incidence와 동일한 train/test 분할을 만든다. 기존 MPI 실험은 새 config에서만 repair 단계를 건너뛰고, original state에서 시작한 SCU forget-only state를 세 번째 비교 model로 저장한다. server는 client raw data를 받지 않는다.

**기술:** Python, PyTorch, torchvision CIFAR-10, mpi4py, NumPy, pytest, CUDA, AWGN 10 dB.

## 전역 제약

- 데이터는 CIFAR-10 train 50,000개와 test 10,000개를 분리해 사용한다. FedOSD clone처럼 둘을 섞지 않는다.
- client 수는 10명, 각 client의 train/test sample 수는 각각 정확히 5,000개/1,000개다.
- 각 client는 정확히 두 label만 보유하고, 각 label은 정확히 두 client가 공유한다.
- class-to-client incidence는 FedOSD `separate_data(..., partition="pat", balance=True, NC=2)`의 label 순서 할당과 동일하다. client 0과 1은 label 0·1을 공유한다.
- original과 client_0 제외 재학습은 같은 `initial.pt`에서 시작하고 각각 200 FedAvg rounds, local epoch 1을 실행한다.
- `SCU`는 원본 SCU의 retained self-sharing을 사용할 수 없는 **whole-client deletion** 조건이다. 따라서 삭제 client의 `L_forget`만으로 encoder와 decoder를 함께 200 local epochs 갱신하는 `SCU forget-only` baseline이다.
- SCU 교사 model은 고정된 original codec이며, target data는 삭제 client 밖으로 전송하지 않는다.
- 이번 config에서는 naive repair와 conflict-aware repair checkpoint를 만들지 않는다.
- 평가는 모든 model에 동일한 public CIFAR-10 test input을 사용하고, 주 지표는 client_0 제외 재학습 model과의 functional gap이다.

## 실행 흐름

```text
같은 initial checkpoint
  ├─ 10 clients × 200 FedAvg rounds             -> origin
  ├─ client_0 제외 9 clients × 200 FedAvg rounds -> retrain
  └─ origin + client_0 local SCU forget-only 200 epochs
                                                  -> SCU
```

`retrain`은 삭제 뒤에 다시 학습하는 model이 아니라, 처음부터 client_0의 학습 데이터를 빼고 학습한 비교 기준이다. `SCU`는 `origin`을 출발점으로 하므로 세 번째 독립 학습이 아니라 삭제 절차의 결과다.

```python
def test_fedosd_balanced_pathological_split_has_two_labels_per_client():
    split = build_fedosd_balanced_pathological_split(
        np.repeat(np.arange(10), 20),
        np.repeat(np.arange(10), 10),
        n_clients=10,
        classes_per_client=2,
        seed=7,
    )

    assert split.train_allocation.sum(axis=1).tolist() == [20] * 10
    assert split.train_allocation.sum(axis=0).tolist() == [20] * 10
    assert (split.train_allocation > 0).sum(axis=1).tolist() == [2] * 10
    assert (split.train_allocation > 0).sum(axis=0).tolist() == [2] * 10
    assert np.flatnonzero(split.train_allocation[0]).tolist() == [0, 1]
    assert np.flatnonzero(split.train_allocation[1]).tolist() == [0, 1]
```
