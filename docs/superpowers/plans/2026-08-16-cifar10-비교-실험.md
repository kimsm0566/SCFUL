# CIFAR-10 비교 실험 구현 계획

> **작업 절차:** 각 구현 단계는 테스트를 먼저 실패시키고, 최소 구현 후 다시 검증한다.

**목표:** MNIST에서 수행한 통제된 client-deletion 비교를 CIFAR-10에도 적용하여, 삭제 전 모델·삭제 대상 제외 재학습 모델·SCU 두 변형의 재구성 및 posterior 차이를 저장한다.

**구성:** CIFAR-10에는 32x32 RGB convolutional codec을 사용한다. Target client는 공유 class 3--6에서 class별 1,500개와 target-specific class 1 전체를 가지며, 나머지 class-1 데이터는 retained set에 포함하지 않는다. 같은 초기 checkpoint에서 삭제 전 모델과 삭제 대상 제외 재학습 모델을 각각 학습하고, 삭제 전 모델에서 SCU forget-only 및 self-sharing을 시작한다.

**도구:** Python 3.10, PyTorch 2.4.1 CUDA, torchvision CIFAR-10, pytest, matplotlib

## 전체 제약

- 재구성 codec의 `encoder -> power-normalized AWGN -> decoder` 경로를 유지한다.
- 성공 지표는 삭제 대상 제외 재학습 모델과의 functional gap이며, target MSE 증가는 보조 진단이다.
- 이번 단계의 SCU self-sharing은 retained raw data를 직접 쓰는 중앙집중식 비교 방법이다. 연합 repair 결과로 해석하지 않는다.
- 모든 산출물은 기존 run을 덮어쓰지 않는 `outputs/cifar10_behavior/` 아래에 저장한다.
- Markdown 문서는 한국어로 작성한다.
