# 중앙집중 Full SCU 비교선 구현 계획

> **에이전트 작업자용:** 이 계획은 작업 단위로 실행한다. 모든 production code는 먼저 실패하는 테스트를 확인한 뒤 최소 구현한다.

**목표:** FedOSD pathological CIFAR-10 split에서 target client data와 pooled retained data를 서버에 일시 중앙화해, 원본 SCU `VAE_unl_ss`에 대응하는 full compensation codec을 학습하고 retrain 기준과 비교한다.

**구조:** `federated_scu.py`에는 central full SCU loss와 학습 함수를 추가한다. `federated_deletion.py`는 original/retrain FL 뒤 모든 client train array를 server에 gather해 full SCU를 한 번 실행한다. 새 config는 `centralized_full_scu`만 허용하며 output은 `original`, `retrain_without_client_0`, `SCU_central_full` 세 checkpoint다.

**기술:** Python, PyTorch, torchvision CIFAR-10, mpi4py, NumPy, pytest, CUDA, power-normalized AWGN 10 dB.

## 전역 제약

- 이 comparator에서만 server는 client 0의 `D_t`와 clients 1--9의 pooled `D_r` raw data를 일시적으로 받는다.
- raw data는 output artifact, checkpoint, log, JSON/CSV에 저장하지 않는다.
- full SCU는 target-only forgetting을 쓰지 않는다.
- `L_TOTAL = L_JU + L_CC`이며, `L_CC`에는 retained reconstruction, prior KL, original SCU의 cosine contrastive compensation이 모두 들어간다.
- dynamic weight는 원본 `VAE_unl_ss`처럼 detached raw loss magnitude로 계산한다.
- original/retrain은 같은 initial state에서 200 FedAvg rounds, local epoch 1로 학습한다.
- `SCU_central_full`은 original state에서 200 local epochs, batch size 200으로 학습한다.
- encoder와 decoder는 모든 SCU step에서 함께 갱신한다.
- Markdown 문서는 한국어로 작성한다.
- workspace root는 Git 저장소가 아니므로 commit/worktree 생성은 수행하지 않는다.

- [x] **Step 1: 실패하는 loss decomposition test를 작성한다.**

```python
def test_full_scu_loss_includes_joint_unlearning_and_compensation():
    total_loss, terms = calculate_centralized_full_scu_loss(...)

    assert terms["contrastive_loss"].item() >= 0.0
    assert torch.allclose(
        total_loss,
        terms["weight_joint"] * terms["joint_loss"]
        + terms["weight_compensation"] * terms["compensation_loss"],
    )
```

- [x] **Step 2: 실패를 확인한다.**

Run: `pytest -q src/tests/test_federated_scu.py::test_full_scu_loss_includes_joint_unlearning_and_compensation`

Expected: `ImportError` because the full SCU loss function does not exist.

- [x] **Step 3: 최소 구현을 작성한다.**

`joint_loss`는 target posterior-to-original KL과 negative target reconstruction MSE다.
`compensation_loss`는 `lambda_ss * (beta * retained prior KL + retained MSE + contrastive ratio)`다. cosine ratio는 target/retained posterior mean과 retained reconstruction을 detach 후 re-encode한 posterior mean을 사용한다. 최종 loss는 dynamic weights를 곱한 두 term의 합이다.

- [x] **Step 4: encoder/decoder joint update test를 작성하고 통과시킨다.**

```python
def test_centralized_full_scu_updates_encoder_and_decoder():
    state, metrics = train_centralized_full_scu(...)
    assert state["encoder.0.weight"].ne(before["encoder.0.weight"]).any()
    assert state["decoder_input.0.weight"].ne(before["decoder_input.0.weight"]).any()
    assert metrics["steps"] == 2
```

Run: `pytest -q src/tests/test_federated_scu.py`

Expected: PASS.

- [x] **Step 3: 최소 구현을 작성한다.**

`_run_centralized_full_scu()`는 all-rank `gather`로 client data를 server에 전달한다. server는 client 0 data를 target, 나머지 data를 concatenated retained dataset으로 만든다. client rank에는 state를 만들지 않고 gather 뒤 반환한다. server는 original state에서 full SCU를 실행하고 raw array reference를 해제한다.

`centralized_full_scu` branch는 repair를 실행하지 않고 세 state만 평가·저장한다. `scu_forget_only`는 config validation에서 거부한다.
