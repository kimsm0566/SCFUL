# 중앙집중 Full SCU 비교선 설계

## 목적

FedOSD balanced pathological CIFAR-10 분할에서 client 0의 전체 삭제에 대해
중앙집중 full SCU가 어느 정도까지 삭제 대상 제외 재학습 model을 근사할 수 있는지
측정한다. 이 비교선은 서버가 target data `D_t`와 남은 9개 client의 pooled
retained data `D_r`를 **실험 중에만** 볼 수 있다고 가정한다.

이 실험의 역할은 full SCU의 centralized compensation 효과를 분리하는 것이다.
향후 federated method는 이 `D_r`가 제공하는 remaining semantic knowledge를 raw-data
중앙화 없이 어떻게 대체하는지를 검증한다.

## 범위

```text
D_t = client_0의 전체 local train data 5,000개
D_r = clients 1--9의 local train data를 합친 45,000개
```

비교 model은 다음 세 개다.

```text
original
  10개 client가 200 FedAvg rounds 학습한 codec

retrain_without_client_0
  같은 initial state에서 client_0을 제외한 9개 client가 200 FedAvg rounds 학습한 codec

SCU_central_full
  original에서 시작해 서버가 D_t와 D_r을 함께 사용하여 200 epochs full SCU를 수행한 codec
```

`SCU_central_full`은 federated method가 아니다. target과 retained raw data를 server에
중앙화하는 것은 이 comparator에서만 허용한다. raw data는 checkpoint, manifest,
prediction artifact, log에 저장하지 않는다.

`forget_only`, target-only forgetting, naive repair, conflict-aware repair는 이 실험에
포함하지 않는다.

## Full SCU 목적식

원본 SCU clone의 `VAE_unl_ss` 구조를 CIFAR-10 semantic codec에 대응한다. 한 step은
target batch `x_t`와 retained batch `x_r`를 함께 사용한다.

```math
L_{JU}^{raw}
= \lambda_{KL} KL(q_U(z|x_t) || q_G(z|x_t))
 - \lambda_{rec} MSE(\hat{x}_t, x_t).
```

`q_G`는 original codec의 freeze된 target posterior다. 따라서 이 항은 target
reconstruction error를 키우면서 unlearned posterior가 original posterior에서 과도하게
벗어나지 않도록 한다.

Retained semantic compensation 항은 다음과 같다.

```math
L_{CC}^{raw}
= \lambda_{ss} \left[
  \beta KL(q_U(z|x_r) || p(z))
  + MSE(\hat{x}_r, x_r)
  + \frac{1 - \cos(z_r,z_r^+)}
         {1 - \cos(z_t,z_r) + \epsilon}
\right].
```

여기서 다음 대응을 사용한다.

```text
z_t   = q_U(z|x_t)의 posterior mean
z_r   = q_U(z|x_r)의 posterior mean
x_hat_r = retained batch의 channel-aware reconstruction
z_r^+ = q_U(z|x_hat_r.detach())의 posterior mean
```

이 대응은 SCU clone의 erased latent, remaining latent, remaining reconstruction을 다시
encoding한 positive latent의 cosine ratio를 reconstruction semantic codec에 옮긴다.
Posterior mean을 사용하므로 contrastive ratio 자체는 posterior reparameterization
noise와 AWGN draw에 흔들리지 않는다. Reconstruction과 VAE terms는 기존 학습과 같은
power-normalized AWGN 10 dB path를 사용한다.

원본 clone처럼 두 raw loss 크기에서 detached dynamic weight를 만든다.

```math
w_{JU} = \frac{|L_{JU}^{raw}|}
               {|L_{JU}^{raw}| + |L_{CC}^{raw}| + \epsilon},
\qquad
w_{CC} = \frac{|L_{CC}^{raw}|}
               {|L_{JU}^{raw}| + |L_{CC}^{raw}| + \epsilon}.
```

최종 loss는 사용자가 정의한 두 항의 합으로 표기한다.

```math
L_{JU} = w_{JU} L_{JU}^{raw},
\qquad
L_{CC} = w_{CC} L_{CC}^{raw},
\qquad
L_{TOTAL} = L_{JU} + L_{CC}.
```

`epsilon=1e-8`은 cosine denominator와 weight denominator의 0 나누기만 막는다.

## Batch exposure와 hyperparameter

원본 SCU clone의 `zip(dataloader_erase, dataloader_remain)` 규칙을 따른다.

- target batch size는 200이고, `D_t` 5,000개이므로 epoch당 25 step이다.
- retained loader는 매 epoch seed를 바꿔 shuffle한다.
- 각 epoch은 target batch 수만큼 retained batch를 사용한다. 따라서 한 epoch에
  `D_r` 45,000개 전부를 고정적으로 순회하지 않고, 5,000개의 shuffled retained example을
  compensation에 노출한다.
- 200 epochs 동안 총 optimizer step 수는 5,000이다.
- `D_r`의 sample exposure는 epoch마다 새 shuffle subset을 통해 누적된다.

Hyperparameter는 original/retrain 설정을 공유한다.

```text
codec                 CIFAR10SemanticCodec, latent_dim=64, base_channels=32
optimizer             Adam
learning rate          1e-4
batch size             200
SCU epochs             200
lambda_KL              1.0
lambda_rec             0.1
lambda_ss              1.0
beta                   1e-4
epsilon                1e-8
channel                power-normalized AWGN, SNR 10 dB
```

## 실행과 artifact

MPI process는 기존과 같이 server 1개와 client 10개다. original과 retrain 학습에는
각 client data가 local에만 존재한다. SCU 단계에서만 각 client가 server에 자신의
in-memory train array를 보내며, server는 client 0을 `D_t`, 나머지를 `D_r`로 합친다.
SCU 종료 후 server는 raw array reference를 해제한다.

각 run은 다음 artifact만 저장한다.

```text
config.json
environment.json
split_manifest.json
checkpoints/initial.pt
checkpoints/original.pt
checkpoints/retrain_without_client_0.pt
checkpoints/SCU_central_full.pt
metrics/summary.json
metrics/per_class.csv
metrics/per_client.csv
run.log
```

`summary.json`에는 full SCU loss trace의 평균·마지막 값과 raw data를 저장하지 않는
scalar diagnostic을 기록한다.

## 검증과 성공 해석

구현 전 unit test는 다음을 확인한다.

- full SCU step은 encoder와 decoder state를 모두 바꾼다.
- `L_CC`가 target과 retained posterior mean의 contrastive ratio를 포함한다.
- target/retained data를 바꾸면 해당 loss component가 변한다.
- full SCU config는 `forget_only`를 허용하지 않는다.
- CPU synthetic MPI smoke에서 세 checkpoint만 생성된다.

정식 결과는 retrain_without_client_0 기준으로 해석한다.

- `SCU_central_full`의 MSE 및 functional gap이 target-only forgetting보다 크게
  줄어들면, centralized compensation이 retained utility와 retrain-equivalent behavior에
  기여한다는 근거다.
- MSE만 회복하고 functional gap이 크면 reconstruction repair만 됐을 뿐 client deletion
  behavior를 근사했다는 결론을 내릴 수 없다.
- full SCU도 기준 재학습 model과 멀다면, 원인은 단순히 centralized retained data의
  부재가 아니라 SCU objective 또는 client-level deletion 자체의 불일치일 수 있다.
